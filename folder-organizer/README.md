

\# folder-organizer

선택한 폴더 안의 파일들을 확장자 기준으로 자동 정리해주는 간단한 파이썬 유틸리티입니다.



\## 기능



폴더 선택 (GUI)



파일 확장자별로 폴더 자동 생성



동일 확장자 파일을 해당 폴더로 이동



폴더 / 확장자 없는 파일은 제외



작업 내역을 log.txt로 기록



실행 전 사용자 승인(y/n) 확인



\## 실행 방법



python organize\_by\_extension.py



1\. 정리할 파일이 든 폴더를 선택

3\. 발견된 항목 수를 확인

4\. y 입력 시 자동 정리



\## 주의사항



선택한 폴더 내부의 파일 위치가 실제로 변경됩니다 



같은 이름의 파일이 이미 존재할 경우, 덮어쓰기 문제가 발생할 수 있습니다



되돌릴 수 없습니다
